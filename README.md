# Solved DSA Questions

A collection of **28 solved problems**, organized by topic. Solutions are written in **Python 3**.

## Topics

| Folder | Problems | Focus |
| --- | ---: | --- |
| [01-Arrays-and-Hashing](./01-Arrays-and-Hashing/) | 22 | Array traversal, hashing, sorting, and greedy techniques |
| [02-Two-Pointers](./02-Two-Pointers/) | 1 | In-place traversal with two indices |

## Common patterns

| Pattern | Typical time | Typical extra space |
| --- | --- | --- |
| Array scan / in-place update | O(n) | O(1) |
| Hash map or frequency counting | O(n) | O(n) |
| Two pointers | O(n) | O(1) |
| Binary search | O(log n) | O(1) |
| Greedy reachability | O(n) | O(1) |
| Sieve of Eratosthenes | O(n log log n) | O(n) |
| Fast exponentiation | O(log \|n\|) | O(1) |
| Euclid's GCD algorithm | O(log min(a, b)) | O(1) |

Each problem folder contains its Python solution and, when available, a problem statement.
